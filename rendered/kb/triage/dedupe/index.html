Current rule

Decision 0002 and the #4471 review replace the subject-only rule in historical decision 0001.

  1. Use normalized subjects to find candidates.
  2. Read the report and verify tenant locale, booking form and channel.
  3. Merge only if the behavior and context support the same cause.
  4. If the tenant is unknown or the body conflicts with the proposed cause, keep it separate for investigation.
  5. Deduplicate export overlaps by report ID; do not count every JSON row as a new report.
Matching subjects are not sufficient evidence. Different subjects do not rule out one cause. When unsure, preserve the evidence and investigate before merging.
